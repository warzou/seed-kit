Action principale

Une action claire, puis des options secondaires si besoin.

SAFE
Mode AP Activer le Wi-Fi secours

Le node cree son propre Wi-Fi de secours et ouvre l'interface recovery.

Afficher le plan

Demande au backend SAFE d'ouvrir le mode AP recovery puis confirme l'etat reel avant d'annoncer le succes.

Retour reseau principal

Reconnecte le node au Wi-Fi principal configure.

Afficher le plan

Demande à NetworkManager de reconnecter uniquement le profil principal enregistré. L'accès réseau peut couper quelques secondes.

Tester le retour au Wi-Fi connu

L'AP peut disparaitre pendant 30 a 40 secondes. Si le Wi-Fi revient, tu seras reconnecte au reseau normal. Sinon l'AP revient.

Afficher le plan

Depuis le mode AP recovery, stoppe l'AP, tente une fois le dernier Wi-Fi connu, puis reste en mode normal si le retour reussit. En cas d'echec, relance l'AP recovery.

SAFE

Watchdog

... Par defaut, le watchdog reste en observation : il detecte et journalise seulement. En mode automatique, il peut ouvrir l'AP recovery apres une inaccessibilite durable.

Declencheurs AP

Si desactive, SSID + IP + route locale suffisent. Une passerelle ou Internet momentanement KO ne declenche pas l'AP.

Bascule AP recovery

... Le Wi-Fi secours s'ouvre seulement si l'echec persiste pendant ce delai.

Retour automatique

... Mettre une duree a 0 desactive la bascule automatique pour cette condition. Les evenements restent journalises.

Logs

Futur : retention 31 jours, maximum 10 Mo, et option Tailscale obligatoire separee.
